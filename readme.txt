Compact Quad-Element Slotted Ground Wideband MIMO Antenna

This repository contains the design files, full-wave electromagnetic simulation models, MATLAB scripts, and project documentation for the Compact Quad-Element Slotted Ground Wideband MIMO Antenna project. Developed as part of the Antenna Engineering (OE4E25) course at PDPM IIITDM Jabalpur under the guidance of Assistant Professor Trivesh Kumar.
Project Overview

This project focuses on the design and simulation of a Four-Element Slotted MIMO (Multiple-Input Multiple-Output) Antenna using CST Studio Suite.

The main objective is to study the antenna's performance in the X-band frequency range and analyze important MIMO characteristics such as return loss, mutual coupling, and radiation pattern.

The antenna geometry is designed with a slotted structure to investigate its effect on impedance matching and isolation between antenna elements.
